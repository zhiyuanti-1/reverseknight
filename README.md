# 反转骑士 Reverse Knight

2D 横版重力反转跑酷小游戏（demo）。Unity 6.4（6000.4.6f1）。

## 怎么玩

**在 Unity 里跑**
用 Unity Hub 打开这个文件夹（Unity 6.4 / 6000.4.6f1），打开 `Assets/Scenes/Prototype.unity`，按 Play。

想双击直接玩，就在 Unity 里 File → Build Settings 打一个 Windows 版到 `Build/`（该目录不入库）。

## 操作

**没有跳跃**。唯一的功能键是翻转重力。

| 按键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| **空格 / J / Shift** | **翻转重力** |
| R | 按住 0.5 秒重开本关 |
| Esc | 暂停 |

菜单里用 `↑ ↓` 选择、`Enter` 确认、`Esc` 退出或返回；选关页也可以直接点按钮或按 `1`–`8`。

翻转分两种：贴地按 → 吸附到对面平面（瞬移）；空中按 → 只改重力方向、不吸附，靠连续按维持在半空。两种翻转都会播同一段 0.08 秒的完整翻面动画。

翻转会保留水平速度，吸附过程中也会带着惯性横向移动并做碰撞扫掠：跑动中翻转不会停顿，横向撞到墙则立即停住；吸附目标按翻转落点采样，换面高度不平时会落到实际经过的那一面。保留比例在 `PlayerMotor.flipHorizontalRetain` 里调，默认 100%。

每关结束后按空格进入下一关；第八关「逆流回廊」结束后按空格返回选关。暂停界面也可以返回选关。

## 关卡进度

前四关采用单路径推进，第四关提供凝固桥与固定石台绕行路线。第五至第八关是新增灰盒：升降井、双面碎桥、摆锤大厅、逆流回廊。
主通道高度压到 4-6 格，用「地面尖刺」和「天花板挂刺」交替出现逼玩家反复翻转。

| 关卡 | 名称 | 尺寸 | 内容 |
|---|---|---|---|
| 1 | FLIP（教学关，背景有文字提示） | 90 × 12 | 4 格通道，6 个翻转点 |
| 2 | BROKEN BRIDGE（断桥） | 150 × 14 | 5 格通道，约 30 个翻转点 |
| 3 | BELL TOWER（钟楼） | 60 × 38 | 五层蛇形向上，顶层是滞空尖刺带 |
| 4 | COOLANT WORKS（熔炉泄压） | 224 × 14 | 搬运冷却核心，选择凝固桥或喷淋减速，躲避后方岩浆 |
| 5 | ELEVATOR SHAFT（升降井） | 44 × 34 | 四层纵向井与五格高的终点层，每层上下口错开成 S 型路线；升降台站上去才启动 |
| 6 | TWIN FRAGILE BRIDGE（双面碎桥） | 100 × 12 | 完整天花板下挂刺、只能走地面碎砖；碎砖天花板段地面有刺，要翻上去；碎砖后还藏着一层刺 |
| 7 | PENDULUM HALL（摆锤大厅） | 110 × 12 | 加大加长的摆锤扫过通道，读摆幅和周期 |
| 8 | COUNTERFLOW（逆流回廊） | 130 × 12 | 六段水流回廊：识流、换面、读压、交错、合流、出口；四处干石岛检查点、上下各两处有预警的泄压水炮 |

第四关越过第24格铜线后开始追逐。蓝色核心碰触拾取，最多携带一枚。经过蓝色接收器自动铺桥，经过顶部琥珀色接收器则让岩浆减速4秒。漏拿核心可以从固定石台绕行。检查点位于64、128、184格，正常经过时岩浆持续推进；死亡重试会恢复当前段物品和桥，将岩浆放回后方18格，准备0.75秒后同时出发。

第五关的 `L` 长升降台与楼面齐平，只有玩家站上去才会启动；每层楼板只在两侧各留一个上下口，形成 S 型路线，玩家必须走到另一侧的下一个口子才能继续向上，不能沿同一列直接飞到顶。第六关完整天花板的下沿挂着 `v` 刺，只能走地面的碎砖；碎砖天花板段的地面有 `^` 刺，要翻上碎砖天花板；碎砖后面还藏了一层 `v` 刺，砖碎后往上撞会死；出生点、检查点和终点留安全落脚。第七关 `O` 是天花板摆锤、`o` 是地面摆锤，锤头是致死后块，摆臂和锤头都加大了。第八关 `>` / `<` 是逆重力浅水石渠，仍是实心平面；下层向右、上层向左，流速 4 格/秒，水纹与泡沫同步加快。按 D 顺流跑速 10、逆流跑速 4，松手随水漂移 4。四处干石岛不会推人。第八关 `t` 生成地面水炮，`q` 生成顶层水炮。水炮会向骑士所在方向瞄准，金环预警共 0.9 秒，最后 0.4 秒锁定炮线。水弹以 18 格/秒沿炮线直飞，理论射程上限 20 格，实际距离受石墙和机关区边界限制。发射周期 2.7 秒。离开作用区或重试会清除脉冲并重置预警。死亡重试也会重置碎裂地板并清掉子弹。

镜头以当前通道的上下两面为竖向中心，横向跟随骑士；升降井按楼层切换，钟楼按楼层平滑切换。楼层切换和地图边缘始终给角色中心上下各留至少 1.5 格视野，死亡回到较低楼层时重新匹配楼层。第五关终点层加高至五格，避免升降台把角色送进屋顶；第六关每段顶部碎桥前后各留三格无吊刺区，供玩家安全换面。岩浆可见前沿与致死判定共用同一位置，HUD距离按角色碰撞盒左边缘计算。

## 关卡怎么改

关卡就是一个 ASCII 文本文件，一行对应一格，从第一行（最上面）往下排：

| 字符 | 含义 |
|---|---|
| `#` | 实心方块（可站立，可翻转后踩） |
| `F` | 碎裂地板，每 3 格一段，独立计时，碎后 3 秒复原 |
| `^` | 地面尖刺（1 格），碰到即死 |
| `T` | 地面长尖刺（3 格，压缩垂直空间） |
| `v` | 天花板尖刺（1 格，朝下） |
| `V` | 天花板长尖刺（3 格） |
| `X` | 天花板挂刺（向下伸 2 格，逼玩家翻回地面） |
| `S` | 弹簧，朝上弹 18 格/秒 |
| `W` | 上升气流区（62），把角色从下层送到上层 |
| `A` | 缓冲上升气流（46），把角色从下往上推 |
| `B` | 缓冲下降气流（46），把角色从上往下推 |
| `M` | 横向移动平台（行程 4 格，从左端出发） |
| `m` | 横向移动平台（行程 4 格，从右端出发，与 `M` 反向运行） |
| `N` | 纵向移动平台（行程 3 格） |
| `L` | 长升降台（行程 7 格，与地板齐平，玩家站上去才启动） |
| `O` | 天花板摆锤（悬挂点在天花板，末端致死） |
| `o` | 地面摆锤（悬挂点在地面，向上摆） |
| `>` | 向右传送带（实心块，站在上面被向右推，带速 3；履带面会滚动，两端有滚轮） |
| `<` | 向左传送带（实心块，站在上面被向左推，带速 3；履带面和箭头朝左） |
| `t` | 向右炮台，定时发射横向子弹，击中即死 |
| `u` | 向左炮台，定时发射横向子弹，击中即死 |
| `C` | 检查点 |
| `G` | 终点 |
| `P` | 出生点 |

改完保存，重新在 Unity 里 Play 就生效；打包版需要重新 Build。
关卡数据直接编辑 txt；仓库里的批量生成脚本未入库，改完后在 Unity 里重新 Play 即可。

背景提示文字在 `Assets/Resources/Levels/levelN_hints.txt`，每行一条：

```
18 5.2 前面过不去\n按 J 翻转重力，双脚会吸到天花板上
```

前面的两个数字是世界坐标（格），后面的文字支持 `\n` 换行。中文用的是系统字体（Microsoft YaHei），运行时通过 `Font.CreateDynamicFontFromOSFont` 加载。

约定：地面与天花板的高度差控制在 4-6 格，全部落在翻转吸附最大距离（6.5 格）以内；翻转动画固定 0.08 秒，吸附目标按横向落点采样。超过 6.5 格的地方就会变成“慢慢飘过去”，那是给气流区用的。

## 手感参数

全部在 `PlayerMotor` 的 Inspector 里，运行中可以直接改：

最大跑速 8、地面加速度 60、地面减速度 90、空中加速度 35、重力 45、最大下落速度 24、
反转过渡 0.08、翻转搜索距离 6.5、翻转水平速度保留 100%。

翻转会保留水平速度并在吸附过程中继续横向移动；把 `flipHorizontalRetain` 调到 0 就回到旧版
「翻一次掉一次速」的手感。

物理固定步长是 1/60 秒（Project Settings → Time），和 60 帧渲染对齐；表现层再把角色在两次固定步之间插值
（`PlayerMotor.smoothRendering`），所以 60Hz / 144Hz 屏幕上跑动都不会出现「一卡一卡」的台阶。
翻转吸附这种单步跨度很大的移动仍然直接跟物理步，避免视觉落后一步、收尾时再突然追上。
用 `-probe` 抓逐帧记录可以直接验证：跑动时 `visualX` 的逐帧位移应该几乎恒定，而物理根节点仍按固定步跳。

跑动帧循环速度在 `PlayerVisual` 的 `runCycleRate` / `runSpeedCycleRate`（次/秒）里调：默认满速约 3.8 次/秒，15 帧共用这个循环时长，所以补间帧不会把跑动节奏拖慢。
把 `PlayerVisual.smoothRunFrames` 关掉就退回原来的 6 帧；15 帧版本更顺，但补间帧的靴子边缘会略糊，可以开关对比。

## 重新打包

命令行：

```
"C:\Program Files\Unity\Hub\Editor\<版本>\Editor\Unity.exe" -batchmode -quit -nographics ^
  -projectPath "D:\这是一个文件夹\游戏\反转骑士" -executeMethod EditorSetup.BuildWin ^
  -logFile build.log
```

或者在 Unity 里直接 File → Build Settings → Build。

## 调试参数（打包版可用）

| 参数 | 作用 |
|---|---|
| `-level 2` | 直接进入第 2 关 |
| `-autoplay` | 自动驾驶（跑、翻转），用于回归测试 |
| `-autoshot <目录>` | 定时截图到目录 |
| `-overview` | 摄像机拉到能看全整关，配合截图看关卡布局 |
| `-probe <csv>` | 逐帧记录角色物理位置/渲染位置/精灵帧，用于检查跑动是否平滑 |
| `-level-regression` | 自动检查第三、五、八关多宽高比镜头、第五关升降台落点和第六关零死亡通关路线；日志输出 `REGRESSION DONE failures=0` 表示通过，完成后自动退出 |

例：
```
Build\ReverseKnight.exe -level 3 -overview -autoshot shots
Build\ReverseKnight.exe -level 1 -autoplay -probe probe.csv
```

## 已知问题 / 下一步

- 骑士已有贴图动画，场景和机关仍是色块/占位；没有音效和音乐。
- 跑动循环是 6 张关键帧 + 6 张中间帧 + 2→3、3→4、4→5 三段各 1 张 1/4 补帧（共 15 帧）。补间帧的靴子边缘在放大看时会有点糊，这是原素材靴子和身体之间有断口导致的；要彻底干净需要重渲染跑动序列。
- 主菜单只有「开始游戏 / 选择关卡 / 退出游戏」三项，没有设置、存档和制作名单页。
- 游戏内 HUD 仍是英文；菜单和背景提示用系统字体显示中文。
- 第五至第八关是灰盒，升降台、摆锤、传送带的节奏还没经过真人试玩调校；双面碎桥和逆流回廊尤其需要真人实测配速。
- 第三关的气流竖井、第二关的移动平台，节奏还没经过真人试玩调校。
