# 反转骑士 Reverse Knight

2D 横版重力反转跑酷小游戏（demo）。Unity 6.4（6000.4.6f1）。

## 怎么玩

**在 Unity 里跑**
用 Unity Hub 打开这个文件夹（Unity 6.4 / 6000.4.6f1），打开 `Assets/Scenes/Prototype.unity`，按 Play。

想双击直接玩，就在 Unity 里 File → Build Settings 打一个 Windows 版到 `Build/`（该目录不入库）。

## 操作

**没有跳跃**。唯一的功能键是翻转重力。

| 按键 | 动作 |
|---|---|
| A / D 或 ← / → | 左右移动 |
| **空格 / J / Shift** | **翻转重力** |
| R | 按住 0.5 秒重开本关 |
| Esc | 暂停 |

菜单里用 `↑ ↓` 选择、`Enter` 确认、`Esc` 退出或返回；选关页也可以直接点按钮或按 `1`–`4`。

翻转分两种：贴地按 → 吸附到对面平面（瞬移）；空中按 → 只改重力方向、不吸附，靠连续按维持在半空。

前面三关结束后按空格进入下一关；第四关结束后按空格返回选关。暂停界面也可以返回选关。

## 关卡进度

前三关采用单路径推进，第四关提供凝固桥与固定石台绕行路线。
主通道高度压到 4-6 格，用「地面尖刺」和「天花板挂刺」交替出现逼玩家反复翻转。

| 关卡 | 名称 | 尺寸 | 内容 |
|---|---|---|---|
| 1 | FLIP（教学关，背景有文字提示） | 90 × 12 | 4 格通道，6 个翻转点 |
| 2 | BROKEN BRIDGE（断桥） | 150 × 14 | 5 格通道，约 30 个翻转点 |
| 3 | BELL TOWER（钟楼） | 60 × 38 | 五层蛇形向上，顶层是滞空尖刺带 |
| 4 | COOLANT WORKS（熔炉泄压） | 224 × 14 | 搬运冷却核心，选择凝固桥或喷淋减速，躲避后方岩浆 |

第四关越过第24格铜线后开始追逐。蓝色核心碰触拾取，最多携带一枚。经过蓝色接收器自动铺桥，经过顶部琥珀色接收器则让岩浆减速4秒。漏拿核心可以从固定石台绕行。检查点位于64、128、184格，正常经过时岩浆持续推进；死亡重试会恢复当前段物品和桥，将岩浆放回后方18格，准备0.75秒后同时出发。

镜头以当前通道的上下两面为竖向中心，横向跟随骑士。钟楼按楼层平滑切换。岩浆可见前沿与致死判定共用同一位置，HUD距离按角色碰撞盒左边缘计算。

## 关卡怎么改

关卡就是一个 ASCII 文本文件，一行对应一格，从第一行（最上面）往下排：

| 字符 | 含义 |
|---|---|
| `#` | 实心方块（可站立，可翻转后踩） |
| `F` | 碎裂地板，每 3 格一段，独立计时，碎后 3 秒复原 |
| `^` | 地面尖刺（1 格），碰到即死 |
| `T` | 地面长尖刺（3 格，压缩垂直空间） |
| `v` | 天花板尖刺（1 格，朝下） |
| `V` | 天花板长尖刺（3 格） |
| `X` | 天花板挂刺（向下伸 2 格，逼玩家翻回地面） |
| `S` | 弹簧，朝上弹 18 格/秒 |
| `W` | 上升气流区（62），把角色从下层送到上层 |
| `A` | 缓冲上升气流（52），把角色从下往上推 |
| `B` | 缓冲下降气流（52），把角色从上往下推 |
| `M` | 横向移动平台（行程 4 格，从左端出发） |
| `m` | 横向移动平台（行程 4 格，从右端出发，与 `M` 反向运行） |
| `N` | 纵向移动平台（行程 3 格） |
| `C` | 检查点 |
| `G` | 终点 |
| `P` | 出生点 |

改完保存，重新在 Unity 里 Play 就生效；打包版需要重新 Build。
用 `python tools/make_levels.py` 可以从脚本重新生成三张地图（会覆盖 txt 文件）。该脚本在本地 `tools/` 里，未入库，克隆后需要自己保留。

背景提示文字在 `Assets/Resources/Levels/levelN_hints.txt`，每行一条：

```
18 5.2 前面过不去\n按 J 翻转重力，双脚会吸到天花板上
```

前面的两个数字是世界坐标（格），后面的文字支持 `\n` 换行。中文用的是系统字体（Microsoft YaHei），运行时通过 `Font.CreateDynamicFontFromOSFont` 加载。

约定：地面与天花板的高度差控制在 4-6 格，全部落在翻转吸附最大距离（6.5 格）以内，而且越窄翻转越快。超过 6.5 格的地方就会变成“慢慢飘过去”，那是给气流区用的。

## 手感参数

全部在 `PlayerMotor` 的 Inspector 里，运行中可以直接改：

最大跑速 8、地面加速度 60、地面减速度 90、空中加速度 35、重力 45、跳跃初速 15、
最大下落速度 24、土狼时间 0.1、跳跃缓冲 0.1、反转过渡 0.08、翻转搜索距离 6.5。

跳跃高度是固定的，没有大小跳，跳多远只取决于起跳时机和速度。

## 重新打包

命令行：

```
"C:\Program Files\Unity\Hub\Editor\<版本>\Editor\Unity.exe" -batchmode -quit -nographics ^
  -projectPath "D:\这是一个文件夹\游戏\反转骑士" -executeMethod EditorSetup.BuildWin ^
  -logFile build.log
```

或者在 Unity 里直接 File → Build Settings → Build。

## 调试参数（打包版可用）

| 参数 | 作用 |
|---|---|
| `-level 2` | 直接进入第 2 关 |
| `-autoplay` | 自动驾驶（跑、跳、翻转），用于回归测试 |
| `-autoshot <目录>` | 定时截图到目录 |
| `-overview` | 摄像机拉到能看全整关，配合截图看关卡布局 |

例：
```
Build\ReverseKnight.exe -level 3 -overview -autoshot shots
```
