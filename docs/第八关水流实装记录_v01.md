## 关卡内容

地图仍为 130×12 格，地面表面 y=3、天花板表面 y=8。沿途没有新增高低台阶，水面视觉嵌在实体石渠内部，不改变碰撞高度。五组上下水道共十段，四处干石岛的上下表面都没有水流。

ASCII 单元内物件以格中心生成，因此喷口的实际中心比草案标注的整数坐标多 0.5 格。脉冲可见前缘在作用区边界前销毁，保证后方换面空档不被残留脉冲侵入。

## 行为

- 水流复用接地带速：松手漂移 ±4，按 D 顺流目标速度 10，逆流目标速度 4；空中不额外叠加水流，翻转仍保留惯性。
- 第八关单独使用 `WaterChannelVisual`。其他关卡仍可使用原传送带表现和原炮台逻辑。
- 喷口只在玩家进入控制范围后开始完整预警，0.9 秒后发射，后续周期 2.7 秒。四门水炮均可追踪瞄准，发射前 0.4 秒锁线，水弹速度 18 格/秒，射程上限 20 格。路径在石墙或机关区边界截断。
- 离开作用范围、死亡重试或通关时清除本喷口脉冲并重置周期；暂停冻结预警。
- 第八关中文选关名、中文 HUD 标题和场景提示已更新。常驻 HUD 保持关名、死亡数与时间，原型图中的流程卡片不进入游戏画面。
- 本轮未新增音频，反馈由水纹、流向箭头、蓄压环和脉冲轮廓提供。

## 验证

Unity Windows 构建成功，编译错误为 0。水流自动回归覆盖：十段水道、无机械滚轮、四门水炮反向斜射命中、超出原 12 格射程的命中、顺逆流速度、干岛停稳、完整首发预警、暂停、离区清理、四个检查点重试、完整零死亡通关及四个检查点沿途激活；结果为 `WATER REGRESSION DONE failures=0`。

此前的第三/五/八关镜头范围、第五关四部升降台和第六关零死亡路线回归也通过，日志为 `REGRESSION DONE failures=0`。自动路线证明基本可通关，真人首次体验与水流节奏仍需试玩调校。

```text
Build/ReverseKnight.exe -level 8
Build/ReverseKnight.exe -water-regression -logFile water.log
Build/ReverseKnight.exe -water-regression -water-shots docs/water_runtime -logFile water-visual.log
Build/ReverseKnight.exe -level-regression -logFile previous-levels.log
```

`-water-shots` 使用真实游戏摄像机渲染保存关卡画面，适用于隐藏窗口，截图不包含 OnGUI HUD。运行日志位于 `tools/water-aim-build.log`、`tools/water-aim-test.log`、`tools/water-previous-levels.log`。
