# 《反转骑士》后续四关设计参考

| 版本 | 日期 | 状态 |
|---|---|---|
| 0.1 | 2026-11-15 | 脑暴稿，未实现，供选型与灰盒 |

现有四关（翻转、断桥、钟楼、熔炉泄压）约 12–18 分钟；本稿讨论第五至第八关，这四关合计约 20–25 分钟，八关总计约 32–43 分钟。如果想把全程压在 30 分钟以内，建议只补两关，或者压缩第七、八关。

扩展到 10 个方案的版本见 [后续十关设计参考](<后续十关设计参考.md>)。

---

## 0. 先定约束

- **机制约束**：没有跳跃、没有战斗、没有道具；所有垂直位移由翻转产生。新增机关必须直接和「在哪一面、什么时候翻」有关，不需要翻转就能过的东西不投入。
- **空间约束**：主通道 4–6 格，任何需要吸附的位置，对面可站面必须在 6.5 格以内；只有气流区允许更长的垂直距离。
- **关卡结构**：单路径、线性推进；检查点后单次重试不超过 20–30 秒；每个新机制先给 10–15 秒无死亡教学，再上危险，再组合。
- **节奏约束**：一关只引入一个新机制；旧机制可以组合，但不要在同一关同时教两个新东西。第八关不再引入新机制，只做总复习与收尾。
- **工程约束**：优先用现有 `# F ^ T v V X S W A B M m N C G P`。新机关用新字符，并且要同步 `LevelDefinition` / `LevelBuilder`，不要做需要重写移动系统的机制。
- **镜头约束**：横向关沿用「通道中心」，纵向关需要像第三关一样配置楼层取景；新纵向关的楼层数控制在 4–5 段，不要让镜头在整张图里乱飘。

## 1. 四个推荐关卡（主线）

### 第五关「风井」Wind Shaft

| 项 | 值 |
|---|---|
| 尺寸 | 约 64 × 36 格，纵向 |
| 时长 | 4–5 分钟 |
| 检查点 | 5 处（每层入口） |
| 预期死亡 | 15–30 次 |
| 新机关 | 无（复用 W / A / B / S / N） |
| 核心考点 | 空中翻转的节奏、用气流托住自己、在两面之间换位 |

**一句话**：塔的通风竖井，风从下往上灌；玩家要在上升气流、下压气流和弹簧之间反复翻转，一层层爬到井口。

**流程**

1. **0–12 格 · 教学竖井**：底部一根 `W` 强上升气流，两侧有平台，没有任何尖刺。玩家站进气流会被托起，学会在上升中按翻转吸附到侧壁。
2. **12–26 格 · 交替风带**：每 3 格换成 `A`（上推）或 `B`（下压），井壁布置 `^` / `X`。玩家必须在每段交界处翻转，用重力抵消推力；不翻就会被推向尖刺。
3. **26–36 格 · 弹簧高台**：`S` 把角色弹向高层，天花板挂刺 `X` 封锁直线，旁边一根短 `W` 修正落点；第一次要求「弹簧 + 空中翻转 + 吸附」三连。
4. **36–50 格 · 风柱阵**：三根 `W` 柱之间隔着空档，底部是 `^`，中间放 `N` 纵向平台。玩家要在柱子之间用空中翻转维持高度，等平台到位再吸附。
5. **50–62 格 · 井口**：`A/B` 交替 + 两面 `X` 的短段，最后到达 `G`。这里只做节奏压缩，不再教新东西。

**示意**（不是完整地图，灰盒时展开）

```text
G   ← 井口：A/B 交替 + 两面挂刺
│
[C] 风柱阵：W  W  W + N 平台
│
[C] 弹簧高台：S + 天花板 X + 短 W
│
[C] 交替风带：A A A / B B B + 井壁尖刺
│
[C] 教学竖井：W 上升 + 侧壁平台
│
P
```

**为什么成立**：第三关已经有气流竖井，但只是「换层工具」；这一关把气流变成主节奏，让玩家第一次真正依赖空中翻转的滞空。它和横向关的体验差异最大，也最能展示「上下都是地面」的世界观。

**技术成本**：低。只需要新楼层取景配置；如果想让风带定时换向，可以加一个很轻的 `AirCurrent` 周期参数，但不加也能成立。

**风险**：纵向镜头和气流速度容易把角色吹出关卡边界；先做灰盒，确认每个 `W` 柱的出口都能落在平台上。死亡多来自「被吹到尖刺」，不是「看不清」，验收时看死亡原因。

### 第六关「齿轮带」Gearworks

| 项 | 值 |
|---|---|
| 尺寸 | 约 180 × 14 格，横向 |
| 时长 | 5–6 分钟 |
| 检查点 | 4 处 |
| 预期死亡 | 20–35 次 |
| 新机关 | 传送带 `>` / `<`（新字符） |
| 核心考点 | 主动选择站在哪一面、顺着带子还是逆着带子、带子换向时的翻转时机 |

**一句话**：废弃的齿轮车间，地面和天花板的传送带朝相反方向跑；玩家要选对那一面，或者在带子换向的瞬间翻到另一面。

**新机关规则**

- `>` / `<` 是带传送带的实心块，可以出现在地面或天花板；带子方向是世界方向（向右/向左），不随重力翻转改变。
- 站在带子上时角色被带子以 3–4 格/秒推动；玩家自己的跑动叠加上去，但总水平速度封顶在最大跑速 8，避免带子把跑速顶穿。
- 带子可以按时间换向（2 秒一次），视觉上用滚动箭头和循环音提示；换向瞬间不强制翻转，但会把玩家往反方向送。
- 传送带和尖刺、移动平台、碎裂地板组合；不需要新的移动系统。

**流程**

1. **0–28 格 · 教学**：地面 `>` 向右、天花板 `<` 向左，带速 3，没有尖刺。玩家先体会「站在哪一面，方向就不一样」。
2. **28–55 格 · 带子 + 尖刺**：地面带把角色送向 `^`，天花板带把他带离；玩家可以逆着跑，也可以翻上去。第一次要求做选择。
3. **55–95 格 · 双带 + 平台**：两段反向带之间断开，中间用 `M` 横向平台接；天花板再挂 `X`，逼玩家在等平台时翻转。
4. **95–130 格 · 换向带**：一段每 2 秒换向的长带，两侧都有尖刺，地面夹 `F` 碎裂段。玩家要等方向正确再走，或者用翻转换到另一面。
5. **130–165 格 · 长带冲刺**：连续三条带 + 移动平台 + 天花板尖刺，第一次不给停顿；检查点放在冲刺前。
6. **165–178 格 · 终点**：最后一条带把角色送进 `G`，上方可选一个 `!` 冲压作为收尾。

**示意**

```text
地面：P  >>>>>>>>>>>>   ^^   >>>>>>   ########   <<<<<<<<   G
天花板：################   <<<<<<<<   XXXX   >>>>>>   ######
```

**为什么成立**：传送带是策划案里已经规划过的正式版机关，和翻转天然配合——同一段路，站地面和站天花板是两种速度、两种方向。它比再加一种尖刺更有信息量。

**技术成本**：中。需要 `LevelDefinition` 认新字符、`LevelBuilder` 生成带 `Conveyor` 组件的块、`PlayerMotor` 在着地时读取带速并做碰撞推进；美术要一条可平铺的带面。没有新输入。

**风险**：带速和跑速叠加容易让关卡变简单或变失控；建议带速先取 3，总速度封顶 8。带子换向要和音效/箭头同步，否则玩家会觉得「被阴」。

### 第七关「崩塌回廊」Collapsing Gallery

| 项 | 值 |
|---|---|
| 尺寸 | 约 150 × 18 格，横向到半纵向 |
| 时长 | 5–6 分钟 |
| 检查点 | 4 处 |
| 预期死亡 | 25–45 次 |
| 新机关 | 冲压锤 `!`（新字符），复用碎裂地板 `F` |
| 核心考点 | 读周期、在两面都被封锁前翻到安全面、边跑边判断 |

**一句话**：塔内档案层正在塌，冲压锤按固定节拍砸下，地板也在脚下碎裂；玩家要在两面之间踩着节奏翻。

**新机关规则**

- `!` 是冲压锤的锚点：贴在相邻实心块上生成，天花板锤向下、地面锤向上；锤头沿竖向轨道运动，周期 2–3 秒，覆盖 2×2 格，碰到即死。
- 冲压锤不阻挡移动，只作为移动的致死后块；它压下来时会把所在的那一面变成「不可站」，逼玩家翻到另一面。
- 可以成对布置：地面锤和天花板锤错开半个周期，形成「这一面安全、那一面危险」的交替节拍。
- 碎裂地板沿用现有 `F`：踩 0.5 秒碎、3 秒复原；死亡重试时恢复。

**流程**

1. **0–30 格 · 脆弱地板**：一条 `F` 横跨尖刺坑，天花板是安全区；玩家学会「地板碎之前翻上去」。
2. **30–60 格 · 单面冲压**：天花板 `!` 按 2 秒周期砸下，地面安全；先跑过去，不要求翻转。
3. **60–95 格 · 交替冲压**：地面和天花板各一排 `!`，相位错开；玩家必须踩着节拍翻面，中间夹 `^` / `X` 逼走位。
4. **95–120 格 · 组合**：`F` + `!` + `M` 平台；地板在碎，锤子在砸，平台在等；检查点放在入口。
5. **120–148 格 · 塌方追逐**：身后的天花板开始连续崩塌，玩家只能往前跑/翻，最后进入 `G`。这一段不要求精确，只要求不回头。

**示意**

```text
P  FFFFF   ^^^      !      !      FFF   >>>  G
###    ###  #####  ####  ####  ###   ###
```

**为什么成立**：冲压锤把「翻转」从空间判断变成时间判断，而且和碎裂地板是同一类压力——都在逼你离开当前那一面。它比再加一种静态尖刺更能提高紧张度。

**技术成本**：低–中。冲压锤可以做成一个带 `Hazard` 的移动物体，不需要改角色物理；塌方追逐可以复用现有的追逐/死亡重置逻辑，或者先用「落块 + 触发区」做简版。

**风险**：冲压锤的周期必须和玩家跑速匹配；太快会变成背板，太慢会变成等待。建议先做单锤灰盒，测出「看到锤子到砸下」的最短反应时间，再决定锤速。

### 第八关「倒悬之顶」The Inverted Spire

| 项 | 值 |
|---|---|
| 尺寸 | 约 220 × 26 格，多段 |
| 时长 | 6–8 分钟 |
| 检查点 | 5 处 |
| 预期死亡 | 30–50 次 |
| 新机关 | 无（总复习：风 / 带 / 碎 / 冲压 / 追逐） |
| 核心考点 | 把前七关学到的读风、读带、读节拍组合起来，在压力下保持判断 |

**一句话**：塔顶没有天空，只有另一座倒悬的塔；玩家穿过最后三段区域，在熔炉核心的追赶下抵达出口。

**流程**

1. **0–60 格 · 外壁风梯**：`W` 柱 + `S` 弹簧 + 两面 `X`，把第五关的纵向节奏压缩成 60 格。
2. **60–120 格 · 齿轮桥**：`>` / `<` 双带 + `M/N` 平台 + 少量 `!`，把第六关的速度选择搬上来。
3. **120–170 格 · 崩塌档案**：`F` + `!` + 短追逐，把第七关的时间压力再压一次。
4. **170–215 格 · 核心追击**：复用第四关的岩浆/冷却核心系统，或换成「从下方追上来的虚空」；玩家一边跑一边翻转，不再有新教学。
5. **215–220 格 · 塔顶**：`G` 前最后一个翻转，镜头拉远，露出上方倒悬的塔身；结算。

**示意**（区块流程）

```text
[风梯 0–60] → [齿轮桥 60–120] → [崩塌档案 120–170] → [核心追击 170–215] → [塔顶 G]
```

**为什么成立**：最后一关不需要新机制，只需要把已经建立的四套语言混在一起，并且用一次追逐给全流程收尾。它也是叙事上的反转：玩家一路向上，最后发现塔顶之上还有一座倒过来的塔。

**技术成本**：内容量大，但机制全部复用。主要成本在关卡拼接、镜头过渡、追逐段调参和结尾演出。注意：现在 `GameManager` 里对 `Levels/level4` 有硬特判才会生成岩浆和冷却工坊，第八关复用前要先把它改成关卡配置。

**风险**：八关总时长可能超过 35 分钟；如果时间紧，可以把第八关的第 4 段缩短，或者把「核心追击」改成短演出而不是完整追逐。

## 2. 备选方案池

如果上面四个里有不合适的，可以直接替换；下面每个都能独立成关。

| 方案 | 核心机关 | 一句话玩法 | 成本 | 适合 |
|---|---|---|---|---|
| 升降井 | `N` 纵向平台 + `M` | 在垂直井里等平台、翻转、再等下一班 | 低 | 替换风井 |
| 双面碎桥 | `F` 两面都碎 | 地面和天花板都在塌，只能不停换面 | 低 | 替换崩塌 |
| 冲压车间 | `!` 冲压锤 | 纯节拍关，两面轮流失守 | 低–中 | 替换崩塌 |
| 摆锤大厅 | 摆锤（新） | 摆锤扫过走廊，数着摆幅翻转 | 中 | 替换崩塌 |
| 风蚀回廊 | `A/B` 横向风 | 横向风把角色往尖刺上推，靠翻转抵消 | 低 | 替换风井 |
| 熔炉续章 | 冷却核心 / 泵 | 把核心送到不同泵站，重复第四关的取舍 | 中（复用） | 替换齿轮带 |
| 单面回廊 | 单向平台（新） | 只能从一面落上去，翻转决定能不能回头 | 高 | 实验位 |
| 冰窖 | 低摩擦地面 | 冰面滑行，翻转后落点更难控 | 低–中 | 实验位，手感风险 |
| 黑暗塔 | 光照半径 | 只能看见身边几格，靠记忆和听声翻转 | 中 | 实验位，非翻转核心 |
| 齿轮迷宫 | 旋转齿轮平台 | 齿轮把角色带着走，翻转跳到另一只齿轮 | 高 | 后期扩展 |
| 坠落天顶 | 触发式落块 | 走过触发线，天花板整块落下 | 中 | 替换崩塌 |
| 双塔镜像 | 传送/镜像 | 翻转后进入上下镜像的另一条通道 | 高 | 后期扩展 |
| 弹簧回廊 | `S` 连弹 | 连续弹簧把角色抛来抛去，只靠翻转修正落点 | 低 | 替换风井 |
| 移动尖刺 | 移动的尖刺墙 | 尖刺墙横向扫过，逼角色换面 | 低–中 | 替换齿轮带 |
| 风带交汇 | `A/B` + 传送带 | 风往一边推、带子往另一边送，选哪一面 | 中 | 组合关 |
| 倒计时逃脱 | 上升的虚空/岩浆 | 追逐 + 翻转，复用第四关逻辑 | 低–中 | 替换第八关追击 |

### 几个备选的具体展开

- **升降井**：60 × 40，四层。每层用 `N` 平台上下 3 格，平台不在同一侧；玩家要算平台周期，在两层之间翻转。没有新机关，适合先做，验证纵向镜头。
- **双面碎桥**：120 × 14。地面和天花板都由 `F` 组成，中间是深坑；玩家不能在任一面停留超过 0.5 秒，必须连续换面。它把第二关的碎地板压力翻倍，代码零新增。
- **冲压车间**：150 × 14。只用 `!` 和尖刺，节奏从 3 秒一锤逐渐压到 1.5 秒；适合做「纯时机关」，但需要防止变成背板。
- **风蚀回廊**：160 × 14。横向 `A/B` 气流（需要让 `AirCurrent` 支持水平方向）把角色往尖刺推，玩家靠翻转改变重力抵消；这是把风井的纵向压力旋转 90°。
- **熔炉续章**：200 × 14。复用第四关的核心/接收器/岩浆，把「一枚核心两种用途」扩展到「三枚核心、三个泵站」；如果第四关的配速还没调好，不建议先做这个。

## 3. 机关库与实现成本

| 机关 | 规则 | 与翻转的关系 | 成本 | 建议字符 |
|---|---|---|---|---|
| 尖刺 / 长刺 / 挂刺 | 接触即死 | 逼玩家换面 | 已有 | `^ T v V X` |
| 碎裂地板 | 0.5 秒碎、3 秒复原 | 不能久留，逼换面 | 已有 | `F` |
| 移动平台 | 横/纵往返 | 等平台、翻转接平台 | 已有 | `M m N` |
| 弹簧 | 向上弹 18 | 抛到另一面 | 已有 | `S` |
| 气流 | 上/下推 | 抵消重力、维持滞空 | 已有 | `W A B` |
| 传送带 | 站在上面被横推 3–4 | 选面、选方向 | 中 | `>` `<` |
| 冲压锤 | 周期上下，碰到即死 | 逼到另一面 | 低 | `!` |
| 触发落块 | 过线后落下 | 逼换面/加速 | 中 | `@` |
| 摆锤 | 摆幅扫过走廊 | 数节拍翻转 | 中 | 新脚本 |
| 单向平台 | 只从一面碰撞 | 翻转决定路线 | 高 | `=` |
| 换向风 | 周期反向的气流 | 等风、翻转抵消 | 低 | `~` 或复用 `A/B` |
| 旋转齿轮 | 旋转平台/危险 | 跳齿轮、卡周期 | 高 | 新脚本 |
| 冰面 | 低摩擦 | 落点更滑 | 低 | `_`（手感风险） |
| 磁力面 | 吸附/排斥 | 改变落面 | 高 | 不建议 |

**优先级建议**：先做传送带（策划案已有、信息量最大）和冲压锤（成本最低、时间压力最直接）；落块、摆锤、单向平台放到下一版；磁力、镜像、旋转齿轮不建议在 demo 阶段碰。

## 4. 四关组合的三种排法

| 方案 | 第五关 | 第六关 | 第七关 | 第八关 | 特点 |
|---|---|---|---|---|---|
| A（推荐） | 风井 | 齿轮带 | 崩塌回廊 | 倒悬之顶 | 纵向→横向→时机→总复习，机制曲线最完整 |
| B（工业线） | 升降井 | 齿轮带 | 冲压车间 | 倒悬之顶 | 全部横向/半纵向，制作最省，但缺少风井的差异化 |
| C（最快落地） | 风井 | 风蚀回廊 | 双面碎桥 | 倒悬之顶 | 只新增冲压锤，几乎零新机制，适合先补足四关 |
| D（实验） | 双面碎桥 | 摆锤大厅 | 齿轮带 | 倒悬之顶 | 三个新机关，风险最高，适合原型验证后再选 |

如果目标只是「再补四个可玩的关」，推荐 C；如果目标是「把后面四个做成正式版内容」，推荐 A。

## 5. 节奏与验收

- **单关节奏**：安全教学 10–15 秒 → 单个机制 + 单个旧机制 60–90 秒 → 组合段 90–150 秒 → 检查点 → 收尾 30–45 秒。
- **检查点**：每个新机制教学后一个；组合段中间一个；追逐/冲压段前一个。单次重试不超过 20–30 秒。
- **死亡预算**：第五关 15–30，第六关 20–35，第七关 25–45，第八关 30–50。超过上限先调间距、检查点、锤速/带速，不要先改重力参数。
- **验收问题**：
  - 玩家第一次遇到新机关，10 秒内能否说出「它和翻转有什么关系」？
  - 每个致死点是否都来自「该翻没翻」或「翻错面」，而不是看不清？
  - 关底是否有一个可以复述的「签名瞬间」？
  - 从检查点重试，是否 20–30 秒内能回到失败点？

## 6. 叙事与美术提示

每关进入时的一行楔子可以继续用第三、四关的冷调：

- 第五关「风井」：风从塔底涌上来，像有人在下面叹气。
- 第六关「齿轮带」：齿轮还在咬合，可它带动的早已不是升降机。
- 第七关「崩塌回廊」：书架在头顶断裂，灰烬先一步落下。
- 第八关「倒悬之顶」：塔顶没有天空，只有另一座塔，倒悬在雾里。

美术上每关给一个主色，避免四关看起来一样：

- 风井：冷青灰 + 布幡/风线；
- 齿轮带：黄铜 + 暖灯 + 滚动箭头；
- 崩塌回廊：灰烬 + 暗红余烬；
- 倒悬之顶：冷白 + 倒置塔影 + 远景雾。

## 7. 下一步建议

1. 先做**第五关风井灰盒**：零新机制，验证纵向镜头和气流节奏；如果镜头/气流不稳，后面的纵向设计都要重估。
2. 再做**传送带单房间原型**（30 × 10）：只验证「站上去被推、翻转后换面、总速度封顶」三件事，不要先铺整关。
3. **冲压锤单房间原型**：验证周期、致死盒和「两面轮流失守」的节拍。
4. 三个原型都过了，再按 A 方案铺第五至第八关；第六、七关各先做一半灰盒，用试玩数据决定后半段是加压还是删减。
5. 最后做第八关；它只复用前七关的机制，不要在终章再引入新机关。

**待定问题**：

- 八关总时长接受 32–43 分钟，还是必须压到 30 分钟以内？如果要压，优先压缩第七、八关，而不是砍掉第五关的风井。
- 传送带是策划案里的正式版内容，是否现在实现？它是四关方案里唯一的中等成本新机制。
- 纵向关的楼层取景是否愿意为第五关再写一套配置？如果不想动镜头，第五关可以改成横向风蚀回廊。
- 第八关的追逐段是复用第四关的岩浆，还是换成新的「上升虚空」？复用最省，但会让第四关的独特性下降。
