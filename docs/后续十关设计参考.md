# 《反转骑士》后续十关设计参考

| 版本 | 日期 | 状态 |
|---|---|---|
| 0.2 | 2026-11-15 | 部分实现：升降井、双面碎桥、摆锤大厅、齿轮带已做成 L5–L8 灰盒；其余仍为方案 |

现有四关是翻转、断桥、钟楼、熔炉泄压。本稿的 10 个方案全部是**新增关**，如果全做，游戏就是 14 关，预计 60–80 分钟；如果只想把总数做到 10 关，就从这 10 个里挑 6 个。

前四个方案（风井、齿轮带、崩塌回廊、倒悬之顶）的完整细节在 [后续四关设计参考](<后续四关设计参考.md>)，这里只做摘要；本稿重点展开新增的六个。

**核心设计原则不变**：一关只引入一个新机制；旧机制可以组合；新增机关必须逼玩家做「翻到哪一面、什么时候翻」的决定。

## 1. 四个保留方案（摘要）

### 1.1 风井

纵向 64 × 36，4–5 分钟，5 个检查点。零新机关，用 `W/A/B/S` 把第三关的「换层气流」变成主节奏：教学竖井 → A/B 交替风带 → 弹簧高台 → 风柱阵 → 井口。考空中翻转、滞空和换面。技术成本低，但需要新楼层取景配置。

细节：[四关稿 · 第五关](<后续四关设计参考.md#第五关风井wind-shaft>)。

### 1.2 齿轮带

横向 180 × 14，5–6 分钟，4 个检查点。新机关 `>` / `<` 传送带：地面和天花板两条带反向跑，玩家选面就是选方向；带子可以定时换向。考速度选择、逆带跑、换向时机。技术成本中：需要 `LevelDefinition` / `LevelBuilder` / `PlayerMotor` 三处配合。

细节：[四关稿 · 第六关](<后续四关设计参考.md#第六关齿轮带gearworks>)。

### 1.3 崩塌回廊

横向 150 × 18，5–6 分钟，4 个检查点。新机关 `!` 冲压锤：天花板/地面按周期砸下，两面轮流失守；复用 `F` 碎裂地板。考节拍、读周期、在两面都被封锁前翻走。技术成本低–中。

细节：[四关稿 · 第七关](<后续四关设计参考.md#第七关崩塌回廊collapsing-gallery>)。

### 1.4 倒悬之顶

多段 220 × 26，6–8 分钟，5 个检查点。零新机关，把风、带、碎、锤、追逐拼成终章；结尾露出倒悬的塔。技术成本是内容量，机制全部复用。

细节：[四关稿 · 第八关](<后续四关设计参考.md#第八关倒悬之顶the-inverted-spire>)。

## 2. 新增六关

### 2.1 升降井 Elevator Shaft

| 项 | 值 |
|---|---|
| 尺寸 | 约 60 × 40 格，纵向 |
| 时长 | 4–5 分钟 |
| 检查点 | 5 处 |
| 预期死亡 | 15–25 次 |
| 新机关 | 无（复用 `N` / `M`） |
| 核心考点 | 平台周期、等待与起跳时机、在平台之间换面 |

**一句话**：一座废弃的升降井，平台按固定周期上下；玩家要等对班次，在平台之间翻转，一层层爬到井口。

**流程**

1. **0–10 格 · 单台教学**：一台 `N` 纵向平台上下 3 格，两侧有固定平台，没有尖刺。玩家站上去、随平台上升、在平台到顶时翻到侧壁。
2. **10–25 格 · 双台错相**：两台 `N` 平台起点不同、周期错开，中间是 `^` 尖刺坑。玩家要等对相位，在一台到顶时翻到另一台，再到侧壁。
3. **25–38 格 · 横纵交替**：`M` 横向平台 + `N` 纵向平台组合；天花板挂 `X`，逼玩家在等平台时换面。第一次要求「横移 + 竖移 + 翻转」三连。
4. **38–50 格 · 平台阵列**：三台 `N` 平台并排，只有一台能到上层；玩家要读相位、在平台间翻转，不能一直站着等。
5. **50–60 格 · 井口**：长竖井 + 移动平台 + 两面尖刺；`G`。

**示意**

```text
G
│  井口：N 平台 + 尖刺
│
[C] 平台阵列：N  N  N
│
[C] 横纵交替：M + N + 天花板 X
│
[C] 双台错相：N  N + ^^^ 坑
│
[C] 单台教学：N + 侧壁
│
P
```

**为什么成立**：它和风井都是纵向，但「读风」变成「读班次」——一个靠持续施力，一个靠等平台。玩家在两种纵向节奏之间切换，不会觉得重复。零新代码，适合先做。

**技术成本**：低。复用现有 `N` / `M`，只加新楼层取景。

**风险**：平台类关卡最容易变成「站着等」。用 2–3 台平台错相、缩短周期、让下一台在视野内，保证每次等待不超过 2 秒；检查点放在每层入口。

### 2.2 双面碎桥 Twin Fragile Bridge

| 项 | 值 |
|---|---|
| 尺寸 | 约 120 × 14 格，横向 |
| 时长 | 3–4 分钟 |
| 检查点 | 3 处 |
| 预期死亡 | 20–30 次 |
| 新机关 | 无（复用 `F`） |
| 核心考点 | 两面都在碎，不能在任一面停留，必须持续换面 |

**一句话**：地面和天花板都是碎裂地板，脚下和头顶同时在塌；玩家只能不停翻转，在两面之间找下一个落脚点。

**流程**

1. **0–20 格 · 教学**：地面 `F` 横跨尖刺坑，天花板是安全区；玩家学会「地板碎之前翻上去」。
2. **20–50 格 · 双面碎**：地面和天花板都铺 `F`，段与段错开半拍；玩家不能在任一面停留超过 0.5 秒，必须连续换面。中间夹 `^^` 尖刺。
3. **50–80 格 · 长段**：两条 `F` 桥平行，中间是深坑 + `X`；加一台 `M` 平台做中继。检查点放在入口。
4. **80–105 格 · 交替收尾**：`F` + `^` + `X` 混合，最后一段要求「翻上去 → 落到天花板 → 再翻下来」两连。
5. **105–118 格 · 终点**：短 `F` 桥接 `G`。

**示意**

```text
天花板：#####FFFFF#####FFFFF#####FFFFF#####
地面：  P  FFFFF  ^^^  FFFFF  ^^^  FFFFF  G
```

**为什么成立**：第二关的碎地板只在地面，玩家可以「贴着天花板看地板塌」；这一关把安全区也变成倒计时，翻转从「选择」变成「必须」。它和升降井一样零新代码，但压力完全不同。

**技术成本**：低。`F` 已经支持任意行；只需要控制每段长度和错相。

**风险**：如果两面同时碎且中间没有落点，会出现无解；必须保证任一瞬间至少有一面有完整段。关卡短一点，检查点多一点，重试不要超过 20 秒。

### 2.3 摆锤大厅 Pendulum Hall

| 项 | 值 |
|---|---|
| 尺寸 | 约 140 × 18 格，横向 |
| 时长 | 5–6 分钟 |
| 检查点 | 4 处 |
| 预期死亡 | 25–40 次 |
| 新机关 | 摆锤 `O`（新字符/脚本） |
| 核心考点 | 读摆幅和周期、在摆锤扫过的空档里翻转/通过 |

**一句话**：钟楼里一排巨大的摆锤来回扫，玩家要数着摆幅，在它抬起的瞬间跑过去或翻到另一面。

**新机关规则**

- `O` 是摆锤的悬挂点，贴在天花板或地面；摆臂长 3–5 格，末端是 1.5 × 1.5 的致死锤头。
- 摆动周期 2.5–3.5 秒，角度 ±60–75°；锤头在最低点扫过通道，玩家必须等它抬起，或者翻到它扫不到的那一面。
- 摆锤不阻挡移动，只作为移动的致死区；可以做单摆、双摆（相位差半个周期）、长摆（几乎覆盖整条通道）。
- 视觉上给摆臂、锤头和地面阴影；入场前先看到一整周期，不要从屏外突然扫进来。

**流程**

1. **0–20 格 · 单摆教学**：一台天花板摆锤，下面平地，没有其他机关；玩家看一个完整周期，学会「等它抬起再走」。
2. **20–50 格 · 双摆错相**：天花板和地面各一台，相位差半个周期；玩家必须翻到安全的那一面，等下一次摆过。
3. **50–80 格 · 摆锤 + 尖刺**：窄通道里摆锤和 `^^` / `X` 组合；安全窗口更短，检查点放在入口。
4. **80–110 格 · 四连摆**：一排四个摆锤，节奏逐渐加快；中间夹 `F` 碎裂地板，不能站定等。
5. **110–135 格 · 巨摆收尾**：一台几乎占满通道的摆锤，只在最高点留一个身位；玩家要翻到天花板/地面躲过，再冲进 `G`。

**示意**（某一瞬间）

```text
O            O
 \            \
  \   ^^^      \        G
###\###########\###########
```

**为什么成立**：冲压锤是「上下砸」，摆锤是「横向扫」；同样是读周期，但玩家的空间判断完全不同。摆锤的运动轨迹可见、可预习，适合做成「看会了再上」的关卡。

**技术成本**：中。需要一个 `Pendulum` 脚本、锤头致死后块、摆臂和阴影美术；不改角色物理。

**风险**：摆锤的判定和视觉必须一致，否则会被骂「明明没碰到」。锤头用略小于视觉的判定盒；每个摆锤的周期固定，不做随机；先做单摆房间，测出玩家能接受的最快周期。

### 2.4 单面回廊 One-Way Gallery

| 项 | 值 |
|---|---|
| 尺寸 | 约 130 × 16 格，横向/混合 |
| 时长 | 5–6 分钟 |
| 检查点 | 4 处 |
| 预期死亡 | 20–35 次 |
| 新机关 | 单向平台 `=`（新字符/碰撞） |
| 核心考点 | 从哪一面接近平台、翻转后能不能回头、路线理解 |

**一句话**：回廊里全是只能从一面落上去的平台；玩家要判断「这一面能不能站」，翻转不只是换重力，也是换路线。

**新机关规则**

- `=` 是单向平台：只从它标记的正面碰撞，从背面可以直接穿过；正面用短箭头/斜线标出。
- 角色从背面穿过时不会吸附，也不会被挡住；从正面落下时会正常站立。
- 重力翻转后，玩家的「下落方向」变了，所以同一块平台在两面世界里的用法不同；这正是关卡要考的点。
- 不做「按向下键穿过」这类额外输入，保持只有翻转一个功能键。

**流程**

1. **0–20 格 · 教学**：一块单向平台悬在坑上，玩家从下面翻上去、穿过平台、落在它正面；没有尖刺。
2. **20–50 格 · 选择面**：一排单向平台，有的只能从上面落、有的只能从下面落；玩家要选对接近方向，走错会掉进坑里。
3. **50–80 格 · 单向 + 尖刺**：单向平台和 `^` / `X` 组合；正面是安全落点，背面是尖刺，翻转决定生死。检查点放在入口。
4. **80–110 格 · 单向 + 移动平台**：单向平台和 `M/N` 组合；玩家要先等平台，再从正确的一面落上去。
5. **110–125 格 · 收尾**：连续三块单向平台，最后一块只允许从背面穿过再翻上来；`G`。

**示意**

```text
=        =        =
   ^^^      ^^^      ^^^
P    ===      ===      ===   G
```

**为什么成立**：它把「上下两面都是地面」推进到「每一面还有正反」，是 10 个方案里最接近解谜的一关；它考的是理解，不是反应，能拉开关卡类型的差异。

**技术成本**：高。现有 `PlayerMotor` 用 `Physics2D.BoxCast` + layer mask 做碰撞，单向平台需要 `BoxCastAll` 后按接近方向过滤，或者给 `OneWay` 单独一层再逐次判断；还要保证不会在平台边缘抖动。

**风险**：单向规则容易让玩家困惑，也容易出现「卡在平台背面」的软锁。必须用非常明确的箭头/斜线视觉，教学段不设死亡，先做单房间原型验证；如果成本压不住，换成「风蚀回廊」或「弹簧回廊」。

### 2.5 坠落天顶 Falling Ceiling

| 项 | 值 |
|---|---|
| 尺寸 | 约 150 × 18 格，横向 |
| 时长 | 5–6 分钟 |
| 检查点 | 4 处 |
| 预期死亡 | 25–40 次 |
| 新机关 | 落块 `@`（新字符/脚本） |
| 核心考点 | 反应、读预警、在落块之间找安全路径 |

**一句话**：天花板在玩家经过时一块块塌下来，落块砸出缺口也砸出新的安全路径；玩家要边跑边翻，不能停。

**新机关规则**

- `@` 是天花板上的落块锚点；玩家经过前方的触发线后，锚点先出现裂纹/灰尘预警 0.3–0.5 秒，然后 2 × 2 的块落下。
- 落块是致死后块，落地后停留 1.5–2 秒再消失/复原；它不阻挡移动，但会把那一段空间变成不可停留。
- 落块位置固定、顺序固定，不做随机；预警必须清楚，玩家第一次看到就知道「这块要掉」。
- 可以和 `F`、`M`、尖刺组合；也可以用连续落块做「天花板追逐」收尾。

**流程**

1. **0–20 格 · 单块教学**：一块 `@`，玩家走过触发线，看预警、等它落下，再从旁边过去；没有其他危险。
2. **20–50 格 · 顺序落块**：三块 `@` 依次落下，形成一条只在前一块落下后才安全的路；玩家要边跑边等。
3. **50–80 格 · 落块 + 尖刺**：落块和 `^^` / `X` 组合；玩家要翻到落块砸不到的那一面，等落块消失再继续。
4. **80–110 格 · 组合**：`@` + `F` + `M` 平台；地面在碎、天花板在落、平台在等；检查点放在入口。
5. **110–145 格 · 天顶追逐**：身后的天花板连续塌落，玩家只能向前跑/翻；`G`。

**示意**

```text
@     @     @
|     |     |
#     #     #
P  ^^^   ^^^   ^^^   G
```

**为什么成立**：冲压锤和摆锤都是「等它过去」，落块是「它已经砸下来了，路变了」——玩家不是等周期，而是读后果。它把「翻转」和「环境被破坏」连在一起，适合做中后段的压力关。

**技术成本**：中。触发线 + 落块动画 + 致死后块，不需要改移动系统；落块用固定脚本，避免随机。

**风险**：最容易做成「不知道怎么就死了」。预警、阴影、声音三件套必须齐全；落块不要从屏外进入；第一次出现时给一个安全观察位。

### 2.6 熔炉续章 Coolant Works II

| 项 | 值 |
|---|---|
| 尺寸 | 约 200 × 14 格，横向 |
| 时长 | 6–7 分钟 |
| 检查点 | 5 处 |
| 预期死亡 | 25–40 次 |
| 新机关 | 无（复用第四关核心/接收器/岩浆） |
| 核心考点 | 资源取舍：最后一枚核心用来铺桥还是减速，路线判断 |

**一句话**：熔炉泄压之后，玩家继续往冷却车间深处走；这一次要同时管理三枚核心和一条越来越近的岩浆。

**流程**

1. **0–30 格 · 复习**：一枚核心 → 蓝槽 → 凝固桥；岩浆在身后启动；短段，不教新东西。
2. **30–70 格 · 两枚核心**：两枚核心、两个蓝槽，中间夹一个喷淋槽；玩家要决定哪一枚铺桥、哪一枚减速。检查点放在入口。
3. **70–120 格 · 三枚核心**：三枚核心、四个接收器；有的路线用桥更短，有的路线用喷淋更安全；玩家不可能全部激活，必须取舍。
4. **120–160 格 · 最后的泵**：一个「总泵」接收器，消耗一枚核心让岩浆停止 6 秒；玩家可以选择停岩浆冲过去，也可以留核心铺最后的桥。检查点放在入口。
5. **160–195 格 · 逃生桥**：最后一枚核心铺桥，岩浆在身后；`G`。

**为什么成立**：第四关已经把「一枚核心两种用途」讲清楚了；这一关把它扩展成「三枚核心、多个接收器、最后一枚怎么花」。它不考新操作，考的是在压力下做资源判断，正好和纯操作的关卡拉开差异。

**技术成本**：中。不需要新机关，但要把第四关的 `LavaChase` / `CoolantWorkshop` 从 `GameManager` 里的 `Levels/level4` 硬特判改成关卡配置，才能复用；总泵是喷淋接收器的一个变体。

**风险**：最容易变成第四关的重复。必须给一个新转折（总泵 / 三枚核心 / 更长的追逐），并且保证「把核心全用在减速上」也有可通关的固定石台路线，不能出现无解。第四关的配速如果还没调好，先别做这一关。

## 3. 十关的推荐顺序

全做的话，建议按「工业层 → 向上 → 塔顶」排；四关稿里的四个方案可以插在中间，不必固定在 5–8。

| 关卡 | 方案 | 作用 |
|---|---|---|
| 第五关 | 熔炉续章 | 紧接第四关，先把资源取舍讲完 |
| 第六关 | 风井 | 从工业层进入通风井，纵向换气 |
| 第七关 | 齿轮带 | 横向速度与选面 |
| 第八关 | 升降井 | 纵向平台节奏，和风井形成对照 |
| 第九关 | 双面碎桥 | 两面压力，短而密 |
| 第十关 | 崩塌回廊 | 冲压锤节拍，进入塔内高层 |
| 第十一关 | 摆锤大厅 | 横向摆动，换一种读周期 |
| 第十二关 | 单面回廊 | 路线/理解关，作为节奏变化 |
| 第十三关 | 坠落天顶 | 反应与崩塌，最后的压力关 |
| 第十四关 | 倒悬之顶 | 总复习 + 追逐收尾 |

总时长：新增十关约 48–59 分钟，加上现有四关约 12–18 分钟，全流程 **60–77 分钟**。如果只想要 10 关总量，就从这 10 个里挑 6 个，建议保留：熔炉续章、风井、齿轮带、崩塌回廊、摆锤大厅、倒悬之顶；把升降井、双面碎桥、单面回廊、坠落天顶作为替换位。

## 4. 新机关成本与替换

| 新机关 | 方案 | 成本 | 主要工作 | 替换建议 |
|---|---|---|---|---|
| 传送带 `>` / `<` | 齿轮带 | 中 | 字符、Builder、着地带速、美术 | 无，策划案已有 |
| 冲压锤 `!` | 崩塌回廊 | 低–中 | 移动致死后块、周期、预警 | 移动尖刺 |
| 摆锤 `O` | 摆锤大厅 | 中 | 摆臂旋转、锤头判定、阴影 | 冲压车间 |
| 单向平台 `=` | 单面回廊 | 高 | BoxCastAll 过滤/单向层、视觉 | 风蚀回廊、弹簧回廊 |
| 落块 `@` | 坠落天顶 | 中 | 触发线、预警、落块重置 | 冲压车间、移动尖刺 |
| 核心/泵复用 | 熔炉续章 | 中 | 把 level4 特判改成配置、总泵 | 双塔镜像（高成本） |

**建议的落地顺序**：

1. **风井灰盒**（零新机制）：验证纵向镜头和气流节奏，成本最低，先做。
2. **齿轮带单房间原型**（30 × 10）：验证站上去被推、翻转后换面、总速度封顶。
3. **冲压锤单房间原型**：验证周期、致死盒和两面轮流失守。
4. **升降井 / 双面碎桥灰盒**（零新机制）：快速补内容，验证平台等待和双面压力。
5. **摆锤 / 落块单房间原型**：验证可读性和预警。
6. **单面回廊原型**：最后做，先验证碰撞过滤；如果成本压不住，直接换风蚀回廊。
7. **熔炉续章**：等第四关配速稳定后再复用。
8. **倒悬之顶**：最后拼，只复用已有的机制。

## 5. 备选池

四关稿里还有 16 个替换方案（升降井、双面碎桥、冲压车间、摆锤大厅、风蚀回廊、熔炉续章、单面回廊、冰窖、黑暗塔、齿轮迷宫、坠落天顶、双塔镜像、弹簧回廊、移动尖刺、风带交汇、倒计时逃脱），本稿已经展开其中六个；剩下的可以作为替换位：

- **想加新体验**：双塔镜像、齿轮迷宫（成本高，建议下一版）。
- **想调节奏**：黑暗塔、冰窖（非翻转核心，谨慎）。

细节见 [四关稿 · 备选方案池](<后续四关设计参考.md#2-备选方案池>)。

## 6. 待定问题

- 这 10 个是全做（14 关），还是只挑 6 个把总数做到 10 关？
- 单面回廊的单向碰撞成本能否接受？不能就换风蚀回廊。
- 熔炉续章要不要复用第四关的岩浆，还是做一个没有追逐的资源关？
- 十关总时长 60–80 分钟是否符合预期？如果要短，优先删升降井、单面回廊、坠落天顶这类可替换位。
- 摆锤 / 落块 / 冲压锤都需要预警美术；音效没做之前，先用阴影和裂纹做可读性。
